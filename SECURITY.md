# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in mycelium-classifier, please report it responsibly.

**Do not open a public issue.**

Instead, [report it privately on GitHub](https://github.com/mycelium-io/mycelium-classifier/security/advisories/new) with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to provide a fix or mitigation plan within 7 days for critical issues.

If you find room data, labels or credentials committed to this repository, report it the same way. They should never be here.

## Scope

This policy covers all repositories in the `mycelium-io` organization. See the [Mycelium security policy](https://github.com/mycelium-io/mycelium/blob/main/SECURITY.md).
